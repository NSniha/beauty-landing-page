## 📖 About the Project

**Velvety** is a beauty and skincare landing page designed for a fictional organic skincare brand. It covers everything a brand page needs: a bold hero section, featured products, a filterable product catalog, brand story, customer testimonials, promotions and a newsletter signup. The layout adapts smoothly to mobile, tablet and desktop screens.

> Velvety is a fictional brand created as a front-end portfolio project. Product names, prices and reviews are placeholder content.

---

## ✨ Key Features

- 🎯 **Hero section** with animations and a clear call-to-action
- 🌱 **Feature highlights:** 100% organic, fits your skin, easy to use
- 🛍️ **Featured products** with name, price and star ratings
- 🔎 **Filterable product grid** with category filters
- 📰 **"As Seen In"** press strip
- 🧴 **Skin diagnosis** call-to-action for personalized skincare
- ⭐ **Customer testimonials** with star ratings
- 🎁 **Promotion cards:** loyalty program, gifting and wellness
- 💌 **Newsletter signup** with a discount offer
- 📱 **Fully responsive** across mobile, tablet and desktop

## 🚀 Getting Started

**Prerequisites:** [Node.js](https://nodejs.org/) (LTS version) and npm.

```bash
# 1. Clone the repository
git clone https://github.com/NSniha/beauty-landing-page.git

# 2. Go to the project folder
cd beauty-landing-page

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Available Scripts

| Command | Description |
| :-- | :-- |
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |
